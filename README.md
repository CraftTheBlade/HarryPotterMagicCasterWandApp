# Magic Caster Wand App

Magic Caster Wand App is a Windows app that turns the **Harry Potter Magic Caster Wand** into a Bluetooth spell controller like the official app.

The app connects to the wand over Bluetooth Low Energy, reads the wand buttons and motion sensor data, learns your spell movements, and triggers custom light and vibration effects directly on the wand.


---

## What The App Does

This app lets you reuse the Magic Caster Wand as a programmable Bluetooth spell controller.

You can:

- Connect to the Magic Caster Wand over Bluetooth
- Read wand button input
- Read wand movement / IMU data
- Train custom spell gestures
- Automatically recognize trained spells
- Play LED effects on the wand
- Play vibration effects on the wand
- Add custom spells
- Pick custom spell colors
- Pick custom light animations
- Test built-in spell effects
- View wand battery/status info
- Enable debug output for raw wand data
- Reconnect the wand if it disconnects

The app does **not** require the official Magic Caster app.

## Requirements

You need:

- Windows laptop or desktop
- Bluetooth support
- Harry Potter Magic Caster Wand
- The included `.exe` file

## How To Start The App

1. Download the `.exe` file from the GitHub release.
2. Put it somewhere easy to find, for example your Desktop.
3. Double-click the `.exe`.
4. Turn on your Magic Caster Wand.
